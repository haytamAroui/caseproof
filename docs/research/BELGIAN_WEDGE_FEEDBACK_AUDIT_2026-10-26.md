# Belgian litigation workflow — commercial and legal feedback audit

**Review date:** 2026-10-26. **Authority:** [principal roadmap](../ROADMAP.md), [complete workflow](../PRODUCT_WORKFLOW.md), [ADR-0016](../adr/0016-belgian-litigation-product-pivot.md), [ADR-0017](../adr/0017-default-private-litigation-matters.md). This is a decision-and-source register, **not legal advice, a market survey, a product quality claim, or authority to process client secrets**.

## Executive decision

**Retain the current seven business responsibilities and the full lawyer journey. Strengthen M2's first usable backend release to a SINGLE scoped, non-LLM factual-reference check:** (A) source/exhibit existence and citation resolution; (B) literal quotation/page fidelity when a quote actually exists; (C) **typed** date/amount/percentage/unit candidate mismatches when the underlying value's *same meaning/role* can be established without guessing. One deterministic run, one consistent source/brief/exhibit snapshot, typed observations and explicit unknown/not-assessed. Do not split these into artificial sequential user modules or promise that every run finds an error. Default to no issue found for an accurately checked clean case; incomplete/ambiguous data are not a pass.

First useful demo input: synthetic or explicitly authorized redacted NL/FR/EN commercial-litigation brief, including a **zero-verbatim-quotation control**, 35-page-scale samples and adversarial facts. Prove output usefulness by paired human review, actionable finding yield, false warnings, reviewer minutes and evidence/citation correctness. Do **not** claim to detect semantic distortion with regex. Deeper paraphrase/uncited opponent counterevidence is a separately evaluated PIV-10/12 capability, not fake determinism.

## First M2 demo acceptance — unified, headless, no frontend

1. Create immutable brief source + `VersionedBrief` and confirmed exhibit register + authorized exact source/representation snapshots. Keep a real doc's index/communication/reviewer states separate.
2. Check each resolved citation in the declared source scope for **exhibit existence**, proper source ID, version, alias, and physical page; never turn unknown/missing into court inadmissibility.
3. Compare **literal quoted text** with a single source-supported span; exact matches, wrong page, duplicate occurrences and incomplete OCR are distinct states. An intentionally *quote-free* brief must still run the next two checks.
4. Parse date/amount/percentage candidates from assertion and referenced exhibit in NL/FR/EN. Only compare matched *roles* (e.g. payment made vs payment made), matching currency/units, applicable precision and referenced line/item/interval. Show both exact source anchors. An unlinked value, different VAT basis, currency, amendment, dates with differing roles, unavailable OCR, negation or multiple candidates → `NEEDS_CONTEXT` / `NOT_ASSESSED`, **not a claimed contradiction**.
5. Log absent/duplicate Stuk/Pièce references as resolution observations; maintain separately `listed_in_inventory`, `in_custody`, `communicated_proven`, `filed_proven`; no implicit boolean equivalence.
6. Produce one structured scope manifest and report with checked vs excluded/unprocessed denominators, exact/unknown candidates, provenance and change invalidation; reviewer sees confirm/dismiss/needs-information dispositions and can reopen the sources.
7. Regression tests: trilingual zero-quote and quote-heavy, clean and adversarial, same-role amount/date differences, unrelated multiple dates, VAT net/gross, changed reference number, aliases and pages, partial scans, mismatched versions, malicious source text, and independent restart. Measure **actionable yield** and **false-warning review time** rather than count of flags. Stable API ports allow M2 code before M1-B cloud release.

**Implementation status (2026-10-26):** PR #63 only adds typed draft-reference literal checks, source/version/alias anchoring and synthetic cross-module regressions. It does **not** yet implement the typed date/value reconciliation above, durable brief graph, user-visible verification report, opponent-wide retrieval, contractual local/offline product, billable certificate or live user/storage/pipeline.

## Opponent mode — separate scoped quality gate

- **Baseline M2:** checks opponent citations against their **confirmed** exhibit set, even if no quote is present.
- **Later evaluated PIV-10/12:** scan all authorized/processed pages of the **opponent's disclosed record**, including uncited pages, for potential qualifying/contrary text. Return exact provenance, nearby context, whether cited, limitations, recall and false-positive metrics. No automatic conclusion of admission, misconduct, contradicting testimony, forensic truth or admissibility.
- **Later PIV-17:** lawyer-approved local procedural authority registry, with passages and effective dates, to explain conditional filing/communication rules; official submission receipts remain external facts.

## Security and business acceptance

For the backend-first path, **M1-A** freezes action/source/exhibit contracts; **M1-B** still requires signed Auth, real scoped RLS, private storage, durable workers, tested OCR and audit. Run local deterministic candidate on nonconfidential fixtures before any confidential demo. A fully local deployment is a separate tested packaging product, not a synonym for running a Python function offline. No claims of compliant "closed environment" before tested architecture and written professional review.

For commercial viability, compare **manual + Hublex + Alice** on the same fixed task (Hublex may intentionally lack source-vs-source semantic checks). Track fewer uncorrected errors, **time to accepted review**, false alarms, confidentiality friction, observed unit cost, repeat use and **actual contracts**. Proposal pricing is an experiment; no fictional disbursement uplift. Client billing and professional secrecy require independent practitioner counsel/bar advice before marketing statements.
