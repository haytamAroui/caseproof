# M0 real-format synthetic NL/FR/EN verification evidence

**Status:** runnable offline generator and exact-byte verifier are implemented. See the PR and CI for actual execution results; do **not** label M0 independently adjudicated. This record is not a certificate of OCR quality, procedural correctness or legal rights over outside material.

## Reproducible generation and verification

```bash
uv run --locked python -m scripts.m0_real_format_fixtures --out /tmp/caseproof-m0-real-formats
uv run --locked python -m scripts.m0_real_format_fixtures --out /tmp/caseproof-m0-real-formats --verify-only
uv run --locked pytest -q tests/test_m0_real_formats.py
uv run --locked python -m scripts.m0_blind_review --out /tmp/caseproof-m0-blind-review
```

The [`kernel-boundary` workflow](../../.github/workflows/kernel-boundary.yml) independently parses generated bytes and uploads the `caseproof-m0-trilingual-real-formats` GitHub Actions artifact (30-day retention).

## Actual generated materials

Every one of the 18 newly authored M0 v3 cases receives a non-empty OOXML DOCX draft with its source reference, UTF-8 inventory that **explicitly records its confirmed/incomplete/unconfirmed status**, and one or more original PDF files. Text PDFs contain actual selectable, extractable source text; image-only PDFs contain real bitmap page images **without a text layer**. The FR clean control additionally receives an **alternate image-only representation** of its text PDF for format coverage, explicitly marked as an alternative, **not a second independent source** or assertion that OCR succeeded. All three NL/FR/EN language cohorts therefore have actual DOCX, searchable PDF, and scanned-only PDF examples; mixed cases also remain present.

The generated `manifest.json` lists file role, byte count, SHA-256, original `source_id`, version, PDF page number, printed page label, and separate bundle page. Validation independently reopens DOCX via python-docx, PDFs via pypdf, asserts scanned pages have page raster images and no extracted text, and checks all hash/size/page-count assertions. Changing a byte fails the test. No remote service, client data or external font file is introduced.

## Honest limitations

- Generated formats are **real files**, but deliberately **fictional**. No competent independent human has agreed to their meaning or labels merely because CI passes.
- The scanner examples are image-only inputs, **not evidence of actual OCR accuracy, calibration or uncertainty thresholds**. The external adjudicator must inspect rendered pages and make a separate decision about expected outcomes.
- This is not the CaseProof production browser or OCR processing pipeline; it verifies fixture integrity, format and version mapping only.
- Historic 19-case v2 material remains unchanged, with its author-only label status.
- Sources and newly derived bytes are declared CC0-1.0/project-authored. That is an authorship/rights declaration, not an external trademark, bar or legal opinion.
