# EI-005 — Paid-workflow gap closure (candidate-only)

## Scope

Comparison basis: AZComply paid QAE component/confirmation, global-first, registry,
reconciliation, signal validation and four-pass implementation. **Adapt patterns;
do not copy Vertex/provider modules, AI Act classification, paid-route permissions
or domain-specific authority.** Requesty remains the only inference provider.

This PR adds:
- Scout discoveries as *bounded, grounded hints* in source-targeted prompts, never as authorized boundaries;
- an explicit application-authenticated boundary confirmation helper that narrows an existing
  unconfirmed span and rejects stale source/representation hashes;
- versioned, per-candidate signal decision records at candidate-validation level;
- Decimal/currency and ISO-date disagreement classification; amendment notes stay unresolved;
- an evidence matrix that preserves contradictions and targets bounded repair without
  treating more model calls as votes or granting approval.

## Safety and release gates

No Kernel changes, no review permission grant, no canonical migration, no production
authentication route, no automatic decision promotion. The trusted application must
authenticate/authorize the reviewer and persist its decision atomically with the case
event/audit state before constructing BoundaryReview. Do not trust a client-supplied
reviewer_reference alone. New confirmed boundaries require a **new run_id** because
request fingerprints change. Existing runs and provider checkpoints are immutable.

The extraction matrix is a targeting aid, not completeness or legal sufficiency.
Human review is mandatory for negation, allegations, conflicting value, amendments,
currency/basis mismatch, or unresolved semantic support.

## Measurement

The existing opt-in Requesty corpus runner is not a reliable accuracy claim: four
synthetic cases only. Before declaring AZComply parity, run a consented,
independently labeled corpus with fixed source/version/model/prompt/config snapshots;
report exact span precision/recall, signal decision accuracy, boundary confirmation
burden, contradiction recall, repair lift, incremental token cost and duration by
global-first / segmented / four-pass. Maintain hold-out cases and an explicit cost
ceiling; **do not silently run billable live Requesty calls in CI**.
