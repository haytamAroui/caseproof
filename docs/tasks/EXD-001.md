# EXD-001 — Finance-first hexagonal foundation

**Status:** implementation in progress on feature branch.

## Goal
Pivot existing CaseProof planning repository to one ExceptionDesk product, with independent evidence primitives and a first finance reconciliation slice.

## Deliverables
- Current README, architecture ADR and finance-first roadmap.
- Immutable source/evidence models with orthogonal verification, corroboration and review states.
- Finance money comparison producing a separate review finding.
- Pure Python unit tests without database or model dependencies.

## Acceptance
- Source reference and quote required for a source-verified assertion.
- A human review does not turn a statement into objective truth.
- Mixed currencies are rejected; `Decimal` is required.
- Difference is a finding, not mutation of extracted facts.
- Kernel does not import finance or external frameworks.
- Tests execute successfully in an isolated Python 3.11+ environment.

## Out of scope
Upload/API/web app, PDF, live DB, AZComply port, legal rules, actual customer documents and deployment.
