# P1 DOCX parser acceptance — 4 November 2026

Scope: synthetic DOCX region inventory and text discovery. Both call the shared defused XML parser. UTF-8 and UTF-16 LE/BE with and without BOM, hostile DTD/entity declarations, ordinary text, and explicit UTF-32 rejection are exercised in `tests/test_p1_xml_encoding_acceptance.py`. The initial PR head `9ec14381e6477121e00c2aa000131d4245ceb1ea` passed the [kernel workflow](https://github.com/haytamAroui/caseproof/actions/runs/41851128432); later changes require final-head CI.

The hostile-package tests cover damaged ZIP data, unsupported compression, duplicate names, traversal and a reduced per-part expansion limit. The discovery adapter reports unknown coverage for decompression failures. The synthetic mutation smoke uses a fixed seed and 256 mutations; its CI process has a 30-second wall timeout and a 512 MiB virtual-memory limit. It is a narrow mutation smoke, not coverage-guided fuzzing, an OS sandbox for production, or proof of a production processing deadline. Relationship and content-type bytes are mutated as archive data, but discovery does not semantically validate those files. No private documents are used.
