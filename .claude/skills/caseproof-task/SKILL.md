# caseproof-task

Task execution protocol: scope one issue, map domain ports, list failure cases, create tests, implement minimal change, run checks, independent review, update documentation, record remaining risks.

## Quality gate
Every change must satisfy CONSTITUTION.md and the task-specific failure tests. Record proof and unknowns; escalate before crossing approval boundaries.
