# CaseProof font assets

Self-hosted variable fonts from Google Fonts (SIL Open Font License 1.1): `ofl/inter`, `ofl/sourceserif4`, `ofl/jetbrainsmono`, and `ofl/spacegrotesk` (`space-grotesk-latin.woff2` + `space-grotesk-latin-ext.woff2`). Each font's OFL text is included alongside the asset (`OFL-*.txt`). Font names and copyright notices are retained in each font and its license. All fonts are served from the same origin; zero external font requests occur at runtime.

Typography roles:

- **Space Grotesk** (`CaseProof Space Grotesk`): CaseProof UI headings, brand lockup, navigation tabs, and buttons.
- **Inter** (`CaseProof Inter`): Dense UI copy, metadata, forms, and notices.
- **Source Serif 4** (`CaseProof Source Serif`): Long legal prose, preserved draft conclusions, and statutory passages.
- **JetBrains Mono** (`CaseProof JetBrains Mono`): SHA-256 digests, step indices, and technical provenance codes.
