# CaseProof font assets

Self-hosted variable fonts from the Google Fonts repository at commit `fbe81817505e8aeadc53cc7a38a2b76fb57c333e`: `ofl/inter`, `ofl/sourceserif4`, and `ofl/jetbrainsmono`. The source TTF files were converted to WOFF2 without subsetting with fontTools and Brotli. Each font is distributed under the SIL Open Font License 1.1; the corresponding OFL text is included alongside the asset. Font names and copyright notices are retained in each font and its license. Fonts are served from the same origin; no Google Fonts requests occur at runtime.
