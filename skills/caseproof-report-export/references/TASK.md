# caseproof-report-export: task checklist

1. Identify requested outcome and relevant CaseProof workflow.
2. Read authoritative repo instructions, actual code, contracts and current status.
3. Record source versions, trust boundary and missing evidence.
4. Implement the smallest complete vertical slice; include negative and uncertainty paths.
5. Run relevant local and CI checks; record exact results, not assumptions.
6. Report outstanding security, legal, accessibility, localization and practitioner gates.
