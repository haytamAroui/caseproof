# caseproof-animation-review

## Authority
Read `AGENTS.md`, `CONSTITUTION.md`, `frontend/BLUEPRINT.md`, generated API contracts and the applicable workflow before acting.

## Procedure
Review demo sequence for misleading certainty, missing abstention, keyboard controls, focus management, reduced motion, timing and mobile readability. Distinguish staged animation from tested functionality.

## Acceptance
Document files changed, tests actually run, sources, missing evidence and unresolved gates. Do not infer backend authorization or legal approval from presentation.
